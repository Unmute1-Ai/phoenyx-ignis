# Roadmap

## 0.1 — Foundations

- Alpine minirootfs build
- Machine Twin inventory
- iwd Wi-Fi manager
- policy-gated Windows Boot Manager entry repair
- signed receipt envelope and CI

## 0.2 — Safer recovery

- detached Ed25519 receipt signatures
- encrypted receipt export
- automatic ESP discovery with ambiguity handling
- BitLocker-aware, read-only Windows inspection
- reproducible ISO and USB image builds

## 0.3 — Extensibility

- versioned primitive plugin API
- policy bundles with offline signature verification
- Machine Twin comparison and drift explanations
- additional Linux and Windows boot repair primitives

## Later

- measured boot integration
- hardware-backed signing keys
- remote assistance with explicit, time-bounded consent
